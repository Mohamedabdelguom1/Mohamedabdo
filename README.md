# 🗂️ المساعد الإداري الآلي لمراكز التدريب

نظام **مجاني بالكامل** يشتغل داخل **Google Sheets** (جداول جوجل) بواسطة **Apps Script** (لغة برمجة مدمجة في جوجل تشغّل الأوامر تلقائياً). ما محتاج سيرفر ولا اشتراك — يكفي حساب Gmail.

## ماذا يغطي؟

| مهمة المساعد الإداري | كيف يتم أتمتتها |
|---|---|
| إدخال البيانات وتنظيمها | نماذج إدخال جانبية + قوائم منسدلة + منع التكرار + زر **فحص وتنظيف** (توحيد الهواتف السودانية والبريد) |
| ملفات المتدربين والكورسات والشهادات | أوراق مترابطة بكود الكورس، عدد المسجلين يُحسب تلقائياً، **إصدار الشهادات PDF** من قالب Docs بضغطة |
| بيانات الفريق والمشرفين والمنسقين | ورقة "فريق العمل" بالأدوار والحالة |
| الجداول والتقارير (Word/Excel) | **لوحة متابعة** داخل الملف + **تقرير شهري .docx** يُرسل للمدير أول كل شهر |
| تذكير المدير بالمواعيد | **بريد يومي** بالمتأخر، مواعيد اليوم، القادم، الكورسات التي تبدأ/تنتهي، ومن ينتظر شهادة. المتأخر يتلوّن بالأحمر |
| تنظيم المراسلات | أي رسالة Gmail عليها **Label** (تسمية) "المركز" تُسجّل تلقائياً كل ساعة مع تصنيف ومتابعة |

## التركيب (10 دقائق)

1. أنشئ Google Sheet جديد باسم المركز.
2. **Extensions ← Apps Script** (الإضافات ← برمجة التطبيقات).
3. احذف `Code.gs` الافتراضي، وأنشئ ملفات بنفس الأسماء الموجودة في مجلد [`apps-script/`](apps-script) وانسخ محتواها:
   - ملفات `.gs`: `Config`, `Utils`, `Setup`, `Reminders`, `Certificates`, `Reports`, `Correspondence`, `Forms`
   - ملفات HTML: `TraineeForm`, `TaskForm`
   - من **Project Settings** فعّل "Show appsscript.json" وانسخ محتواه (المنطقة الزمنية الخرطوم).
4. احفظ، ارجع للجدول وحدّث الصفحة ← تظهر قائمة **🗂️ المساعد الإداري**.
5. اضغط **1) تجهيز النظام** ← وافق على الصلاحيات (أول مرة فقط).
6. افتح ورقة **الإعدادات** وعدّل: بريد المدير، ساعة التذكير، إلخ.
7. اضغط **2) تفعيل التذكير والتقارير التلقائية**.

> بديل أسرع للمبرمجين: `npm i -g @google/clasp` ثم `clasp create --type sheets` و`clasp push` من داخل `apps-script/`.

## قالب الشهادة

1. أنشئ ملف Google Docs بتصميم الشهادة واكتب فيه هذه الكلمات حيث تريد:
   `{{الاسم}}` `{{الكورس}}` `{{المدرب}}` `{{التاريخ}}` `{{رقم_الشهادة}}` `{{المركز}}`
2. انسخ **ID** الملف (الجزء الطويل في الرابط بين `/d/` و`/edit`) وضعه في الإعدادات.
3. أنشئ مجلد Drive للشهادات وضع الـ ID حقه كذلك.
4. غيّر حالة المتدرب إلى **مكتمل** ← من القائمة **🎓 إصدار شهادات المكتملين**.

## المراسلات

- في Gmail أنشئ تسمية (Label) باسم **المركز** (أو أي اسم تكتبه في الإعدادات).
- أضف فلتر Gmail يطبّق التسمية تلقائياً على رسائل العمل ← تنزل في ورقة "المراسلات" كل ساعة.
- غيّر الحالة إلى "تم الرد" أو حدّد "متابعة بتاريخ" ← تظهر في تذكير المدير عند حلول التاريخ.

## الحدود المجانية (حساب Gmail عادي)

- 100 بريد يومياً من السكربت — التذكير برسالة واحدة يومياً، فالحد كافٍ جداً.
- 6 دقائق لكل تشغيل — مناسب لمئات المتدربين.
